# Knitspace

> 本地优先的个人数字工作台：把今天、知识库、创作、复习与工具收进五个稳定空间。

Knitspace 不试图复制所有软件，也不把每一个点子做成孤立页面。它先覆盖学生和开发者高频的本地流程：收集材料、写 Markdown、整理错题和单词、做代码/图片表达、处理文件，以及回到今天真正要做的一件事。

默认工作流是：选择输入 → 调整参数 → 预览影响 → 生成新输出 → 查看任务历史。

## 命名

**Knitspace** 是唯一面向用户和 GitHub 的产品名：`Knit` 表示把收集、知识、创作、复习与工具之间的关系织起来，`space` 表示这些内容留在一个由自己掌控的本地空间中。它强调的是稳定的个人工作流，而不是无边界的“万能工具箱”。

仓库中少量 `ToolKnit`、`toolknit://` 和 `.toolknit` 是早期版本留下的兼容命名，分别承担应用标识、桌面事件和既有 Vault 索引/恢复数据的稳定性。新界面、文案、文档、导出文件和发布页统一使用 Knitspace；不要在没有迁移方案的情况下重命名这些内部兼容键。

## 产品边界

| 空间 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| 今天 | 专注计时、纪念日、最近任务和学习脉冲 | 复杂项目管理 |
| 知识库 | Markdown、资料、单词、错题与复习 | 在线协作式文档 |
| 创作 | 代码分享、图片标注、轻量图文表达 | 替代完整 PS / Visio |
| 复习 | 题目、答案、解析、错因和 FSRS 复习 | 通用考试题库平台 |
| 工具 | 可预览的本地文件处理与开发者小工具 | 无边界的“万能菜单” |

公开版只保留可复用、可测试的核心能力。个人开发版可通过“私人工具包”的本地清单接入个人脚本；GitHub 发布构建会在前端和 Rust 编译阶段移除该页面与执行器，脚本和本机配置也不会进入仓库或发布包。

公开 Core 与私人工具包的实际构建边界、示例清单和发布检查见 [PUBLIC_CORE.md](PUBLIC_CORE.md)。

## 当前状态

### 已验证

- Windows Tauri 调试版可编译启动；应用图标、SQLite 资料库基础、Credential Manager API Key 存储已具备。
- 文件处理中心：PDF 合并、按页拆分、旋转、提取/重排页面、文字层提取、中文水印、页码、图片转 PDF、PDF 转图片（PNG/JPG/WebP，可调分辨率、质量与页码范围）；图片裁剪、旋转、缩放/压缩、PNG-JPG-WebP 转换；JSON 格式化、文本/Markdown 清理；哈希去重与批量命名预览报告。
- 图片表达工作室：单图、双图、四宫格拼图，标题、水印、方框/箭头/文字/打码/涂色标注（打码在导出时渲染为真实马赛克，涂色为可调粗细的自由画笔，文字双击即可再编辑）和本地 PNG 分享卡导出；标注画布支持 Ctrl+滚轮缩放、空格拖动平移与全屏画布（带浮动工具条），画布会自动占满可用空间；拼成长图把最多 60 张图片按上下或左右方向拼成一张 PNG，间距可为 0（无缝）、正数（留白）或负数（后一张叠压前一张），并支持三种尺寸策略：统一大小（同样格子，居中留白或裁满）、统一宽度（每张缩放/放大到同一宽度，可锁定纵横比或拉伸到统一宽高）与尺寸上限（不放大，只按最大一张封顶）。
- 保存后的图片画布是 Vault 中正式的 `diagram` 内容：打开或保存会进入“最近使用”，可从画布右键、创作页、知识库或 Ctrl+K 收藏并找回；全局列表只读取标题、源图数量与标注数量，不加载源图。删除画布会在同一个 SQLite 事务中清理收藏和最近指针。
- 滚动长图：可导入连续截图，也可在 Windows 桌面版临时注册 `Ctrl+Alt+P` 采集当前前台窗口；结束会话后在 Worker 中一次性识别重叠并生成 PNG，快捷键会随页面或会话结束注销。
- 离线文字识别：使用 Windows 10/11 自带 OCR 和本机已安装语言包处理 PNG、JPG、BMP、GIF、TIFF 与 WebP；结果先进入可编辑确认区，再复制、存为 Markdown 笔记或转成待整理题目，图片不会上传或自动归档。
- 本机语音转写与字幕校对：用户自行选择兼容的 `whisper.cpp` CLI 和 `.bin` / `.gguf` 模型，Knitspace 通过 FFmpeg 提取临时 16 kHz 音轨并生成新的 SRT，再载入虚拟化时间轴校对；媒体不会上传、不会进入 WebView，停止任务会清理临时音轨与未完成草稿。
- AI 内容工作台：摘要、翻译、改写、结构化信息提取和邮件草稿；显示实际发送载荷，结果只作为可复制/导出的草稿。
- 每次文件工具都下载/生成新输出，不覆盖输入文件，并在操作台保留本次输入、输出或错误记录。
- 收集与归档、PDF 区域框选、Markdown 笔记/错题、FSRS 复习、工具配方（复用参数）和用户自带 OpenAI 兼容 API 草稿动作；每张复习卡会保留完整的 FSRS 调度状态，旧的间隔记录会在下一次评分时自动升级。
- 结构化单词支持多词性、多义项、常用搭配、例句与易混词，也支持粘贴或读取 CSV、TSV、TXT 批量导入；本机 Worker 先解析并给出问题预览，重复词可选择合并细节或跳过，桌面版以单个 SQLite 事务写入，失败不会留下半份词表。
- 结构化题目支持从 CSV、TSV、TXT 批量收集题干、答案、解析、错误做法、错因、学科、难度、知识点与错误类型；带换行的 CSV 单元格仍能完整保留。导入前可逐行预览、右键复制或排除，重复题默认跳过且不改动已有 FSRS 进度，桌面端将 Markdown、FTS 与复习卡作为一个批次提交。
- 快速捕获可以把粘贴文本直接整理为结构化题目或单词：常见的“题目 / 答案 / 解析 / 错因 / 学科 / 标签”会进入题目字段，“v. / n. / 词形 / 例句 / 搭配 / 近义词”会保留为多个独立义项。解析完全在本机、输入与条目数量有界；右键或 `Shift+F10` 仍可在笔记、题目、单词和常用片段之间选择，不需要先去对应页面建空记录。
- 桌面资料导入会直接复制原文件到 Vault，而不是先转换成浏览器 Data URL；图片和 PDF 只在选中后通过受限本地资源协议预览。
- 打开或关联外部 Markdown 时，`images/`、`../assets/` 等标准相对路径的本地栅格图片会保留；仅在滚动到附近时读取单张图片，并限制为 12 MB，避免长笔记一次占满内存。
- 从网页、在线文档或富文本编辑器复制内容后，Markdown 编辑器会在普通粘贴时保留标题、强调、链接、列表、引用、代码块和表格结构；`Ctrl+Shift+V` 与右键菜单仍可明确粘贴为纯文本。转换在本机完成，并对输入、节点和输出设置上限，避免异常剪贴板拖慢窗口。
- Windows 安装包注册 `.md`、`.mdx`、`.markdown` 与 `.mkd` 编辑关联；从资源管理器打开文件会直接进入同一个 Knitspace 窗口。冷启动和应用已运行两种情况都由原生内存队列接管，文件绝对路径不会写进 URL、`localStorage` 或前端持久化状态。
- 任意空间都可按 `Ctrl+O` 打开本地 Markdown；工作区空白处和桌面标题栏右键也提供同一入口。多选文件会通过一次性内存交接进入知识库，不把绝对路径塞进路由或持久化状态。
- 工作区空白处的右键菜单会随“今天、知识库、创作、复习、工具”切换高频动作，并保留打开 Markdown、收集剪贴板、浏览全部功能与全局搜索。菜单动作直接引用五空间导航元数据，新增能力不会再形成另一套隐蔽入口。
- 笔记支持 Obsidian 风格的 `[[笔记标题]]`、`[[笔记标题#段落]]` 和 `[[标题|别名]]`：阅读时可点击跳转，右键可创建缺失笔记或建立关系；回链由 SQLite 查询，不在桌面端扫描全部 Markdown。侧栏可按标签和资料夹筛选，资料夹是可嵌套的 Vault 元数据，不会移动外部 Markdown；右侧检查器还提供由已渲染标题生成的文档大纲，可快速定位长笔记。
- 代码分享工作室：按行自动排版并分页导出 PNG、连续长图或 PDF，可切换窗口主题、语言、行号和署名；代码粘贴固定读取纯文本，不会把 IDE/网页剪贴板转换成 Markdown，复制代码也不会混入行号、窗口装饰、额外空行或注释。
- 今天：专注计时、完成记录和每年循环的纪念日。计时状态在切换页面或重开应用后按真实结束时间恢复，不在每秒产生磁盘写入；右键记录可编辑、复用或删除。桌面端的今日与最近 7 天统计由 SQLite 按本地时区从完整事件账本聚合，不会因为页面只加载最近 120 条记录而少算。
- 性能策略：大型 Markdown 的解析留给 Worker；PDF 查看、PDF 导出、Mermaid、标注画布与代码编辑器按需加载，不让未使用的能力拖慢普通页面。Worker 首次预览只保留可读的原始代码和公式，语法高亮与 KaTeX 会在滚动到附近后再处理。超过 768 KB 的 Markdown 不会在输入时自动构建整篇预览 DOM，仍可在阅读时按需加载完整排版。资料库首屏只读取轻量索引，图片/PDF 预览与区域裁剪保存在 Vault 的 `assets/` 下，选中资料时才读取。
- `pnpm check:startup` 会读取生产 `index.html` 真正引用的入口 JS/CSS，分别检查原始与 gzip 体积，并限制首屏资源总 gzip；PDF、Mermaid、画布等按需块不计入首屏。该门槛在 `pnpm build` 后进入 GitHub CI，防止重型依赖被意外改成静态导入。
- 原生窗口支持缩放到 Tauri 配置的 900 × 680 下限：此时五空间导航收成 76px 图标栏，页面根画布不会被固定最小宽度撑出窗口。`desktop-layout.test.ts` 会同时检查 Tauri 下限、根画布约束和紧凑导航断点的层叠顺序。
- Markdown 压力回归：`pnpm benchmark:markdown` 会生成约 1、3、5 MB 三档标准长文档，涵盖标题、公式、代码、表格、任务、相对图片、Mermaid 与超长单行；使用 `pnpm benchmark:markdown:check` 校验结构，也可单独生成 `:1mb`、`:3mb` 或 `:5mb` 档位。`pnpm benchmark:markdown:render` 会用应用同一份 Worker 渲染器同时报告冷解析、首次缓存、热预览和安全分段数；`pnpm benchmark:markdown:gate` 会重复五次并检查冷/热中位数、缓存收益、HTML 膨胀率和分段数，GitHub CI 会在灾难性退化时直接失败。`pnpm benchmark:markdown:all` 可在改动编辑器后连续校验并跑完整三档；可追加 `-- --size=3 --runs=5` 聚焦某个档位。该时间只覆盖 Markdown 解析和延迟占位输出，不把视口外的 KaTeX、语法高亮、Mermaid 或 DOM 挂载混入结果。
- Markdown 工作区底部持续显示字符、行数和预计阅读时间；点击可查看中英文、段落、标题与代码行详情，右键或 `Shift+F10` 可复制摘要或立即重算。统计在独立 Worker 中防抖执行，不会为了更新字数在主线程扫描大型笔记。

## 开发

只检查网页界面时使用：

```powershell
pnpm install
pnpm dev
```

这只是浏览器预览，不包含 Vault、系统剪贴板、文件关联、OCR 等桌面能力。

安装 Rust stable 和 Visual Studio C++ Build Tools 后，日常桌面开发统一使用：

```powershell
pnpm desktop:dev
```

该命令会同时启动 `127.0.0.1:1421` 的前端服务和 Knitspace 桌面窗口，并在前端或 Rust 代码变化时重载。终端必须保持运行；由这条命令生成或覆盖的 `src-tauri\target\debug\knitspace.exe` 是开发壳，固定连接开发服务器，不能脱离 `pnpm desktop:dev` 单独双击。同一路径之后也可能被调试打包命令覆盖，因此不要靠这个原始文件名判断模式，日常独立运行请使用下面的安装包。服务器停止后看到 `ERR_CONNECTION_REFUSED` 并不是应用被安装成了网页，而是开发壳失去了它的热更新页面。

需要一个不依赖 Vite、可以像普通桌面软件一样安装和启动的调试版时，使用：

```powershell
pnpm desktop:package:debug
```

然后安装 `src-tauri\target\debug\bundle\nsis\Knitspace_0.1.0_x64-setup.exe`。这个 NSIS 包会把生产前端资源嵌入应用，关闭终端后仍可独立运行；发布版则使用 `pnpm desktop:package`。

准备公开 Core 前执行：

```powershell
pnpm build
pnpm check:public
```

Windows 本地构建工具可安装到非系统盘；本项目已验证自定义安装目录下的 Rust 原生层编译。

## 数据与隐私

- 处理工具默认临时读取文件并生成新输出；长期资料可选择归档到 `KnitspaceVault`。
- 资料、复习、时间记录和个人脚本清单优先保存在本机；SQLite 保存可检索元数据，Markdown 与大型资料资源分别存入 Vault 文件夹；浏览器预览仅使用受限的本地降级存储。
- 桌面版会在启动空闲后每天创建一次完整 Vault ZIP 归档，归档放在资料库旁并保留最近 7 份；它以流式方式处理大文件，不将整份资料读入内存。
- API Key 仅存 Windows Credential Manager，不进入资料库、备份、日志或 Git。
- AI 仅在用户明确点击动作后发送用户选择的文本；远程地址必须使用 HTTPS，`localhost` 除外。
