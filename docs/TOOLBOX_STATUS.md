# Knitspace 工具箱现状与发布路线

更新日期：2026-08-17（Asia/Shanghai）

这份文档把“万能工具箱”拆成可验收的能力包。它不把一个功能完成百分比当成产品成熟度，也不把尚未接入的外部引擎写成已经支持。

## 已落地的工具平台

- `ToolDefinition`、统一工具目录、工具空间搜索、深链接和工作流卡片。
- Worker、Rust 原生和受控外部 CLI 三类执行边界；任务有进度、取消、重试、输出和历史。
- 本机能力页提供统一 Engine Registry：以固定参数探测 FFmpeg、FFprobe、7-Zip、qpdf、LibreOffice、Tesseract、ImageMagick、ExifTool、Czkawka 和 yt-dlp；不会执行用户输入的命令，也不会自动下载引擎。
- 可保存/导入/导出 JSON 配方，限制步骤数和参数大小；文本流水线支持每步独立预览、条件分支、失败即停、跳过或最多重试 2 次，已有文本处理、文件处理和媒体任务可以复用同一套任务记录。
- 快速处理入口会根据文件类型或粘贴内容推荐下一步：PDF、图片、代码、JSON、JWT、Base64、URL 和普通文本。JWT 只解码，不验证签名。

## 当前已实现的功能包

### 文件与归档

- ZIP、TAR、TAR.GZ；Windows 上检测到用户自行安装的 7-Zip 时可使用 7Z。
- 归档列表、内容预览和解压；拒绝绝对路径、路径穿越、符号链接、设备名和超出条目/展开大小上限的输入。
- 文件健康扫描：重复文件、相似图片（安装 Czkawka CLI 后以固定只读参数运行）、空文件/空目录、大文件、常见扩展名与文件头不匹配、最大目录。
- 两个目录的差异比较、文件 SHA-256 清单导出；需要处理的文件默认进入 Windows 回收站，而不是永久删除。

### PDF

- 合并、拆分、旋转、提取/重排页面、文字层提取、页码、水印、可视签名图层、图片转 PDF、PDF 转图片。
- 可视签名支持输入签名文字、选择左下/居中/右下位置并调整大小；它只是绘制到每页的新图层，不是 PKI 数字签名，不验证身份，也不会锁定 PDF。
- PDF 结构优化：Windows 桌面版有 qpdf 可用时，会在受控临时目录中重写对象流、压缩流并生成新文件；浏览器继续使用 PDF 引擎的结构优化。
- PDF 密码保护与移除：Windows 桌面版使用 qpdf 生成 256 位 AES 加密副本，可选择打印、复制和修改权限；密码只在本次任务内使用，不写入任务历史。
- 按文本匹配的永久栅格化脱敏、页面 CropBox 裁剪。
- PDF 文字工具支持只读查看 AcroForm 字段，或按字段名 JSON 填写文本、复选框、下拉框、选项列表和单选框；每次都生成新 PDF，不提交、不覆盖原 PDF。
- PDF 页面级差异报告：按页比较两份 PDF 的文字层和页面尺寸，输出只读 TXT；新增、缺失、文字/尺寸变化会分别列出，扫描件或超长文字页标记为“未验证”，不伪装成像素级比较。
- PDF 内嵌附件提取：按安全文件名和源文件前缀导出附件；单个 PDF 最多 128 个、单个 16 MB、总计 64 MB，无法读取或超限时停止，不执行附件内容。
- PDF 书签只读导出：保留标题、层级、链接、样式和目标存在性为 JSON；深度 32、节点 4,096、标题和链接长度均有限制，不改动原 PDF。
- PDF 书签编辑：可用受控 JSON 替换书签树，支持 Unicode 标题、页码跳转、http(s) 链接、粗体/斜体/颜色和嵌套层级；拒绝脚本、文件链接与任意 PDF Action，始终生成新 PDF。
- PDF 元数据只读导出：保留基础信息、XMP 标量字段、权限编号、指纹和页面尺寸为 JSON；字段、值长度和页面数量均有限制，不改动原 PDF。
- Windows 本机 OCR 生成可搜索 PDF；原文件不覆盖。

### 图片与媒体

- 图片裁剪、旋转、缩放/压缩、PNG/JPG/WebP 转换、拼图/长图、标注、真实马赛克和元数据清理。
- 桌面版检测到 ExifTool 时可只读查看 EXIF、XMP、IPTC、GPS 等元数据摘要；输出字段和单次执行时间均有上限，不写入任务历史。
- FFmpeg 媒体探测、音频抽取、M4A/WAV/MP4 转换、静音视频、普通/无损截取、MP4 重新封装。
- FFmpeg 音量标准化：音频输出 M4A；带视频的输入复制画面与字幕轨并输出 MKV，音频使用受控 `loudnorm` 重新编码。
- FFmpeg 音频降噪：使用固定 `afftdn` 参数降低持续背景噪声；纯音频输出 M4A，带视频的输入复制画面与字幕轨并输出 MKV，原文件不会覆盖。
- FFmpeg 视频动图：从受限时间区间生成 GIF 或 WebP，固定 12 fps、最长 30 秒、无音频；GIF 使用调色板优化，原视频不会覆盖。
- FFmpeg 只读内容检测：按固定阈值扫描静音区间（−35 dB / 0.35 秒）和黑场区间（0.40 秒 / 10%），结果限制为 256 段，不生成或覆盖媒体。
- FFmpeg 只读音频波形概览：固定 1 kHz 单声道采样并绘制最多 1,600 个峰值；超过 3 小时只采样前段，不生成或覆盖媒体。
- FFmpeg 章节读取与编辑：探测章节列表，并按受限 JSON 生成新的媒体副本；章节最多 1,000 条、标题最多 256 字符，`[]` 可清空章节，不接受任意 FFmpeg 参数。
- 无损移除音轨或内嵌字幕轨；从 SRT/VTT/ASS/SSA/SUB/SMI 加入外部字幕并封装为新的 MKV（字幕路径固定为本地文件，单文件上限 5 MB）。
- FFmpeg 外部字幕烧录：把受限本地 SRT/VTT/ASS/SSA/SUB/SMI 渲染进新 MP4 的视频画面；视频会重新编码，原媒体和字幕文件保持不变，路径通过固定过滤器转义后传给 FFmpeg。
- 从媒体提取第一条文字字幕为 SRT、提取视频封面、清除容器元数据；所有操作生成新文件，不覆盖输入。
- SRT/WebVTT 导入、粘贴、转换、平移、拆分/合并、本机 Whisper 转写；校对台提供 CPS、单行长度、过短时长、重叠和重复正文提示。
- 字幕时间轴安全修复：按开始时间稳定排序，消除重叠并修正非负开始/最小时长；只改时间、不改正文，修复前需确认。

### 开发者工具

- JSON、JSONPath、JSON Schema、JSON/YAML、CSV/JSON、XML、HTML 实体、SQL。
- JSON 样例类型生成：在本地生成 TypeScript、Java、C# 或 Go 的接口/类/结构体；只根据样例推断，不执行代码、不连接网络。
- Base64、Base32、Base58、Hex、URL 编解码；JWT 查看、SHA-256、UUID、时间戳、整数进制、正则、文本 Diff。
- IPv4 CIDR、颜色转换、Cron 解释、日期计算、二维码生成/识别。
- GZip/Deflate 与 Base64 载体互转；压缩工具只处理 UTF-8 文本，设置 2 MB 文本和 8 MB 流上限，不宣称支持 Brotli。

### 本地工作台能力

- Markdown 编辑/阅读、外部文件冲突恢复、Vault/SQLite/FTS、备份恢复、收藏和最近使用。
- 题目、单词、FSRS 复习、剪贴板历史、AI 草稿动作、图片分享卡、思维导图和 Mermaid。
- Windows OCR、whisper.cpp 本机转写、文件关联、桌面快捷键和受控私人工具包；公开 Core 构建会移除私人工具执行器。

## 尚未完成的高风险或外部引擎能力

下面这些是明确的后续任务，不应在发布说明中写成“已支持”：

- qpdf 的签名和更完整的图片压缩策略，以及 qpdf/LibreOffice/Tesseract/ImageMagick/ExifTool/Czkawka 的更完整功能适配、版本策略和 Engine Registry 的安装/更新管理；目前已完成 qpdf 密码/权限、只读探针和受控 PDF 结构优化、ExifTool 受控元数据摘要，以及 Czkawka 相似图片的只读结果适配，但不会自动下载或更新外部引擎。
- PDF 数字签名/提交（当前已有可视签名图层，但仍缺少证书签名）、PDF/A 和 Office/HTML 转换。
- 媒体说话人分离；章节高级样式/批量模板仍未覆盖（当前已支持基础外部字幕烧录、固定音频降噪和短片段 GIF/WebP 动图）。
- 字幕翻译、本地模型管理、图形字幕 OCR、更完整的 CPS/行长自动修复和说话人分离。
- 局域网发现/TLS 配对/断点续传、下载归档和 yt-dlp；这些能力要先完成威胁建模、版本更新和路径参数白名单。
- 监控文件夹、定时运行和跨设备同步。
- PowerToys 类窗口 Hook、键盘映射、多显示器布局等系统级功能。

## “完成一项功能”的验收门槛

每个后续功能必须同时满足：

1. 接入现有工具目录、搜索、深链接或工作流，不新增不可发现的孤立页面。
2. 明确输入、输出、覆盖策略、取消行为、失败恢复和权限声明。
3. 补充纯逻辑测试；跨模块任务再补 TypeScript 构建、生产启动预算和 Rust/引擎检查。
4. 默认生成新输出；删除或移动操作必须先扫描、预览并可回收/回滚。
5. 提交到 `main` 后等待 GitHub Actions 的完整 `verify` 成功，再进入下一项。
6. 只清理项目目录中的构建产物和临时目录，不能用仓库根目录递归删除代替清理。

## 发布前的下一阶段

### 真实工作流验收

用固定输入验收以下八条黄金路径：

1. PDF 导入 → OCR → 优化 → 导出。
2. 图片批量缩放 → 清元数据 → 重命名。
3. 视频无损截取 → 移除/加入字幕轨 → 提取字幕 → 转写 → QA。
4. Markdown 编辑 → 外部修改 → 冲突恢复。
5. CSV 单词导入 → FSRS 复习 → 撤销评分。
6. 文件夹扫描 → 查重 → 预览 → 回收站。
7. JSON 粘贴 → 智能识别 → 转 YAML → 保存配方。
8. Vault 备份 → 升级 → 恢复并校验。

每条路径都要测正常、取消、错误、重启、输出校验和“不覆盖输入”。

### Windows Beta 矩阵

- Windows 10/11；100%、125%、150%、200% 缩放；1366×768、1920×1080 和多显示器。
- 中文用户名、空格路径、超长路径、无 FFmpeg/Whisper/OCR 语言包、磁盘空间不足和 Vault 被占用。
- 安装、覆盖安装、旧数据库迁移、升级失败恢复、卸载和异常退出后的文档/任务恢复。

### 公开发布

- 发布构建必须使用 Public Core；跑 `pnpm build:public`、`pnpm check:public` 和普通/公开 Cargo 检查。
- 建立依赖、外部引擎、许可证、SBOM、SHA-256 校验和签名说明。
- 在干净 Windows 虚拟机执行安装、升级、卸载，并在 Beta/RC 阶段公开反馈入口。

## 项目范围内的清理方式

先预览，再只对已经确认的项目路径执行：

```powershell
git clean -ndX -- dist src-tauri/target .tmp-7z-test2
git clean -fdX -- dist src-tauri/target .tmp-7z-test2
```

这不会触碰 C 盘其他目录；测试写入系统临时目录的代码必须在测试结束时自行删除。
