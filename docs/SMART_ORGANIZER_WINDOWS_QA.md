# 智能整理 Windows 验收矩阵

本清单区分可重复的隔离自动化、需要用户显式选择目录的 OneDrive 验收，以及不能在普通 CI 中安全模拟的安装与显示环境。

## 自动化边界

`pnpm desktop:e2e` 会构建独立应用标识的 E2E 二进制，并在临时目录验证以下文件系统行为：

- 确认前扫描和摘要读取零变更；
- 同盘移动、凭据、撤销；
- 输入变化和目标占用时拒绝执行且不覆盖；
- 部分失败反向回滚；
- 跨盘只复制、保留原件并可撤销；
- 应用被强制终止后在下一次启动恢复 pending 凭据；
- 只读文件移动和撤销后仍保持只读属性；
- `FileShare.None` 独占锁定的文件不产生目标或凭据；
- 单个组件合法、总路径超过 260 个 UTF-16 单元的中文文件名可执行并撤销。

测试只递归删除由自身创建且名称带 `knitspace-e2e-` 或 `Knitspace-E2E-OneDrive-` 前缀的精确子目录。普通和 Public Core 构建不包含故障注入字段、进程 PID 或 WebDriver 权限。

## 显式 OneDrive 验收

常规 CI 不会猜测或写入 OneDrive。需要在已登录 OneDrive 的 Windows 机器上显式运行：

```powershell
if (-not $env:OneDrive) { throw '当前用户没有可用的 OneDrive 根目录。' }
$env:KNITSPACE_E2E_ONEDRIVE_ROOT = $env:OneDrive
try { pnpm desktop:e2e } finally { Remove-Item Env:KNITSPACE_E2E_ONEDRIVE_ROOT }
```

该用例只在所选根目录中新建一个 `Knitspace-E2E-OneDrive-*` 子目录，完成扫描、移动、撤销和正文校验后删除它。它验证普通本地可用同步文件，不代表“仅联机”占位文件已经验收。

## 仍需真机人工验收

| 场景 | 操作 | 必须观察到的结果 |
| --- | --- | --- |
| OneDrive 仅联机占位文件 | 在专用测试目录放置仅联机文件，扫描后选择执行 | 明确成功下载并处理，或在零变更状态给出可理解错误；不能留下半成品或覆盖目标 |
| OneDrive 同步冲突 | 执行前从另一设备修改同一测试文件 | 执行前重校验停止，原件和远端版本均不被覆盖 |
| 只读目录/受控文件夹访问 | 把归档根设为无写权限的专用测试目录 | 写恢复日志或创建目标失败时零文件变更，错误不泄露绝对路径 |
| 125%/150% DPI | 分别在两种缩放下完成扫描、计划编辑、凭据与撤销 | 表格、冲突状态、确认按钮和回滚入口可见且可键盘操作 |
| 安装包升级 | 用测试 Vault 安装上一版本，生成一份未撤销凭据，再安装候选版本 | Vault 可打开、schema 正常、旧凭据可查看/撤销，应用标识和数据目录不漂移 |
| 中途退出安装/应用 | 在候选版本执行整理时强制结束进程并重新启动 | 自动恢复，或保留“需人工处理”凭据；任何情况下都不覆盖文件 |

记录结果时只保存版本、场景、数量、状态和错误码；截图与缺陷描述须遮盖用户名、绝对路径、正文和同步账号。
